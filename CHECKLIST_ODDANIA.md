# Checklista przed oddaniem projektu

1. Utwórz repozytorium GitHub.
2. Wgraj kod projektu do repozytorium.
3. W README uzupełnij adres repozytorium w sekcji `Repozytorium`.
4. Sprawdź `ffmpeg -version`, a następnie uruchom projekt przez `npm install` i `npm start`.
5. Sprawdź stronę główną i `embed-demo.html`.
6. Sprawdź upload zwykłego MP4 oraz przynajmniej jednego AVI/MKV i upewnij się, że wynik trafia do `public/uploads` jako MP4.
7. Sprawdź kolejkę, sekcje, komentarze i import/eksport JSON.
8. Do ZIP-a nie dodawaj katalogu `node_modules`.
9. W ZIP-ie zostaw `package.json`, żeby zależności można było zainstalować przez `npm install`.
10. Upewnij się, że w `docs/` jest dokumentacja PDF.
11. Oddaj ZIP oraz link do GitHub zgodnie z wymaganiami prowadzącego.
