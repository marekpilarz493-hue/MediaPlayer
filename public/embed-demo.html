Przykładowa istniejąca strona

Ten dokument udaje zwykłą stronę, do której dołączono komponent MediaPlayer przez CSS i JavaScript.

Minimalny kod osadzenia

<link rel="stylesheet" href="assets/css/player.css">
<div id="my-player"></div>
<script src="assets/js/media-player.js"></script>
<script>
  new MediaPlayer('#my-player', {
    playlist: [
      { title: 'Mój film', src: 'media/moj-film.mp4', sections: [] }
    ]
  });
</script>

Jeżeli komponent jest osadzony w innym katalogu lub hostingu, trzeba dopasować ścieżki do plików CSS, JS i filmu.
